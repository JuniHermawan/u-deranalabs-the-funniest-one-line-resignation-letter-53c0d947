The one-line resignation letter of a retry loop that has had enough: it waited 1s, then 2s, then 4s, then 8s, the server still said nothing, so it is done doubling. One line, 107 characters, flat and tired, no wasted words.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
